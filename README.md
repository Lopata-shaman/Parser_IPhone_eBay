# 📱 eBay iPhone Price Monitor Bot

A Telegram bot designed to automatically monitor iPhone listings on eBay and find deals priced below market value.

## 🚀 Key Features
- **Smart Filtering:** Select specific iPhone models and versions (e.g., Pro, Pro Max, Plus).
- **Price Control:** The bot monitors listings and filters for offers that are **lower** than your specified price threshold.
- **Instant Notifications:** Receive direct links to profitable deals via Telegram the moment they are detected.
